# Change Log
All notable changes to this project will be documented in this file.
This project adheres to [Semantic Versioning](http://semver.org/).

## Unreleased

## [1.1.0] - 2026-11-13
- Implemented Julia observers for Metal, Nvidia and AMD energy measurements.
- Extended observers in general. 
- Implemented automatic handling of floating point types.
- Improved timing stability. 

## [1.0.2] - 2026-10-25
- Improved and updated dependency management. No breaking changes.

## [1.0.1] - 2026-08-21
- Set to correct PyPI kernel-tuner reference. No breaking changes.

## [1.0.0] - 2026-08-21
- Full initial release. 
- No breaking changes compared to 0.0.4.

## [0.0.4] - 2026-08-21
- Improved handoff of libnvrtc between Python and Julia in underlying kernel_tuner (breaking changes).
- Minor QOL improvements.
- Gearing up towards initial full release.

## [0.0.3] - 2026-08-19
- Improved automatic conversion of outputs to Julia (breaking - changes).
- Expanded tests.
- Gearing up towards initial full release.

## [0.0.2] - 2026-08-19
- Included additional commonly used functions.
- Improved automatic conversion of Julia arrays (breaking changes).
- Expanded tests.
- Gearing up towards initial full release.

## [0.0.1] - 2026-08-01
- Initial alpha version.
